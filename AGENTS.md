# Repository working rules

These rules apply to all automated agents and contributors working in this repository.

1. Never create commits directly on `main`.
2. Before changing files, create or switch to a branch named `feature/<short-description>`.
3. Never push directly to remote `main`; push the feature branch for review and integration.
4. Keep source code in `src/`, tests in `tests/`, assets in `assets/`, configuration in `config/`, documentation in `docs/`, and development utilities in `tools/`.
5. Do not commit generated builds, caches, secrets, credentials, or machine-local settings.
6. Keep changes focused, test them in proportion to risk, and update related documentation.
7. Do not select or add an engine-specific directory layout until the engine decision is documented.
